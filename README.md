# TOPO App 🐾

Ứng dụng học tiếng Anh trẻ em tương tác - TOPO (Chủ đề Động Vật Nuôi).

## 🚀 Live Demo
- [Trải nghiệm trực tiếp trên GitHub Pages](https://25phongsusu.github.io/topo-app/)

## ✨ Tính năng
- Học từ vựng theo chủ đề với hình ảnh minh họa sinh động
- Phát âm chuẩn & âm thanh tương tác vui nhộn (Tone.js)
- Trắc nghiệm phản xạ, ghép thẻ và pháo giấy chúc mừng (Canvas Confetti)
